Build rules — what the system enforces
Palette
  • Components use role tokens only (--fg, --fg-muted, --surface, --rule-*, --change, --btn-*), never palette values
  • Oxblood is the change mark on light surfaces and the closing-plate ground. Never emphasis
  • Five surfaces: white, bond, ink, navy, oxblood. Brass on dark surfaces only
  • No change mark on oxblood; --change is transparent there
Typography
  • Archivo only — no second typeface
  • 600 headings · 500 labels/eyebrows · 400 body
  • Sentence case everywhere, including the wordmark
  • Never set "OS" apart in caps, another color, or a block
Layout & geometry
  • No gradients, rounded containers, drop shadows, or icon tiles
  • Linework only — fill="none", stroke geometry, 1–2px rules
  • Rules span containers, not grid cells — a section divider goes on the wrapper
  • In auto-fit grids, every cell carries identical padding and borders
Mark and glyphs
  • Use the files in svg/; don't redraw them
  • Four product glyphs only, a documented family. No icon set
  • Light rows: ink primary, graphite secondary, --c-mark delta
  • Dark rows: white primary and secondary, --c-mark-lift delta
Starter prompt — paste at the top of any new session
Read BRAND_SYSTEM.md and brands/construction-os/BRAND.md before writing any CSS.
Use role tokens from tokens.css (--fg, --fg-muted, --surface, --rule-*, --change, --btn-*). Never hard-code a color.
Archivo for display, headings, labels and numerals; Source Serif 4 for body prose only.
No gradients, shadows, rounded containers, pill badges, all-caps labels or monospace.
Oxblood (--change) marks a change only, never emphasis. Buttons are ink.
If a treatment isn't in BRAND_SYSTEM.md, add it there first. Don't invent it in page code.
